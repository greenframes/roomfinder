Interaktiver Raumfinder fuer Tagungs-, Seminar- und Veranstaltungsraeume. Besucher werden per gefuehrtem Wizard automatisch zu passenden Raeumen geleitet.

== Description ==

P20 Raumfinder ist ein eigenstaendiges WordPress-Plugin, mit dem Besucher anhand ihrer Anforderungen (Personenzahl, Anlass, Dauer, Bestuhlung, Technik, Verpflegung) automatisch passende Raeume finden.

Alle Raeume, Preise, Ausstattungsmerkmale und Verpflegungsoptionen werden vollstaendig im WordPress-Backend gepflegt - kein Code noetig.

Einbindung ueber Shortcode:

`[p20_raumfinder]`

Optional steht auch ein einfacher Gutenberg-Block "P20 Raumfinder" zur Verfuegung.

== Installation ==

1. Plugin-Ordner "p20-raumfinder" als ZIP packen (falls noch nicht geschehen).
2. WordPress-Backend -> Plugins -> Installieren -> Plugin hochladen.
3. ZIP auswaehlen, hochladen, aktivieren.
4. Im Menue "Raumfinder" Raeume, Ausstattung und Verpflegung anlegen bzw. die Startdaten pruefen.
5. Shortcode [p20_raumfinder] auf der gewuenschten Seite einfuegen.
